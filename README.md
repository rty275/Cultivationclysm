This is inspired in part by cultivation novels in general, computer-engineer-man's Mana Cores mod, and by just a desire to mess around with a lot of the aspects of Cataclysm json coding that I haven't fooled around with. Feel free to leave suggestions in the issues if you have any ideas, but I give no guarantees that I'll accept them, nor that I'll necessarily keep working on this mod at all, at least not at the moment. If it gets popular enough, who knows? 

It's not actually necessary to use this with another mod that uses mana, because mana is used here to cultivate, the cultivation techniques that enhance it are still useful for more cultivation if nothing else.

Look around in mansions, museums, and places where the more exotic martial arts manuals are found to find your cultivation techniques. Or, use the setting that ignores proficiencies and just get your athletics skill high enough to auto learn them all.

Balance not guaranteed, though I've at least made a slight attempt with it. For the most part, cultivation provides greater and greater returns the more you invest in any given technique, and it is effectively free aside from the mana cost and calories of the exercise, but of course by default it is balanced as all true roguelikes do. Random spawn chance!
